## Description

Prevents decay within Tool Cupboard radius. Wipe-aware UI, team-aware auth, debug overlay, and TC preview holograms. Oxide v2.0.7022+ (Rust Naval Update); verified against Oxide 2.0.7423.

## Installation

1. Download `ModernNoCupboardDecay.cs` from the latest release.
2. Upload it to `oxide/plugins/ModernNoCupboardDecay.cs` on your server.
3. The plugin compiles and loads automatically; a default config is written to `oxide/config/ModernNoCupboardDecay.json` on first load.
